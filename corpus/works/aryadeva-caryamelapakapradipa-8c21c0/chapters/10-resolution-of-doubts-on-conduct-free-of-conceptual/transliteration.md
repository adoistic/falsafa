**CMP 10.1**

mahāṭavīpradeśeṣu phalapuṣpādyalaṅkṛte / parvate vijane sādhyamidaṃ dhyānasamuccayam //

**CMP 10.2**

sevayan kāmaguṇān pañca jñānārthirāgiṇaḥ sadā // iti /

**CMP 10.3**

kāyavākcittavajrāṇāṃ kāyavākcittabhāvanam / svarūpeṇaiva tatkāryaṃ laghusiddhiravāpyate //

**CMP 10.4**

jaṭāmukuṭadharaṃ bimbaṃ sitavarṇanibhaṃ mahat / kārayed vidhivat sarvaṃ mantrasaṃvarasaṃvṛtam //

**CMP 10.5**

ṣoḍaśābdikāṃ gṛhya sarvālaṅkārabhūṣitām / cāruvaktrāṃ viśālākṣīṃ prāpya vidyāvrataṃ caret //

**CMP 10.6**

locanāpadasaṃbhogairvajracinhaistu bhāvayet / mudrāmantravidhānajñāṃ mantratantrasuśikṣitām //

**CMP 10.7**

kuryāt tāthāgatīṃ bhāryāṃ buddhabodhipratiṣṭhitām / guhyapūjāṃ prakurvīta catuḥsattvāṃ(sandhyaṃ) mahāvratī //

**CMP 10.8**

kandamūlaphalaiḥ sarvaṃ bhojyabhakṣyaṃ samārabhet / evaṃ buddho bhavecchīghraṃ mahājñānodadhiḥ prabhuḥ //

**CMP 10.9**

ṣaṇmāsenaiva tatsarvaṃ prāpnuyānnātra saṃśayaḥ / vane bhikṣāṃ bhramennityaṃ sādhako dṛḍhaniścayaḥ //

**CMP 10.10**

dadanti te bhaya[tra]stā bhojanaṃ divyamaṇḍitam / atikramanti yadi vajrātmā nāśaṃ vajrākṣaraṃ bhavet //

**CMP 10.11**

surīṃ nāgīṃ mahāyakṣīmasurīṃ mānuṣīmapi / prāpya vidyāvrataṃ kāryaṃ trivajrajñānasevitam // iti /

**CMP 10.12**

dvayendriyasamāpattyā vyāyāmavidhirantare / harṣacittaṃ muneḥ siddhau mahāsukhamiti smṛtam //

**CMP 10.colophon**

niṣprapañcacaryāmelāvaṇasaṃśayaparicchedo daśamaḥ // 10 //
