**CMP 4.1**

dūraṅgamekacaramaśarīraṃ guhāśayam / ye cittaṃ sanniveśayanti mucyante mārabandhanād // iti /

**CMP 4.2**

pratītyotpadyate yadyadindriyairviṣayairmanaḥ //

**CMP 4.3**

tanmanastvaśītikhyātasrakārastrāṇanārthataḥ // iti /

**CMP 4.4**

saṃvittimātrakaṃ jñānamākāśavadalakṣaṇam / kintu tasya prabhedo 'sti sandhyārātridivātmanā //

**CMP 4.5**

ālokālokabhāsau ca tathālokopalabdhakam / cittaṃ trividhamityuktamādhārastasya kathyate //

**CMP 4.6**

vāyunā sūkṣmarūpeṇa jñānaṃ sanmiśratāṃ gatam //

**CMP 4.7**

niḥsṛtyendriyamārgebhyo viṣayānavalambate //

**CMP 4.8**

ābhāsena yadā yukto vāyurvāhanatāṃ gataḥ / tadā tatprakṛtiḥ sarvā astavyastā pravartate //

**CMP 4.9**

yatra yatra sthito vāyustāṃ tāṃ prakṛtimudvaheta // iti /

**CMP 4.colophon**

cittavivekasaṃśayamelāvaṇaparicchedaścaturthaḥ // 4 //
