**CMP 3.1**

pañcavarṇaṃ mahāratnaṃ sarṣapasthūlamātrakam / nāsikāgre prayatnena bhāvayedyogataḥ sadā // iti /

**CMP 3.2**

pañcajñānamayaṃ śvāsaṃ pañcabhūtasvabhāvakam //

**CMP 3.3**

niścārya padmanāsāgre piṇḍarūpeṇa kalpayet / pañcavarṇaṃ mahāratnaṃ prāṇāyāmamiti smṛtam //

**CMP 3.4**

atha bhagavān mahāvajrī vajrajāpārthabhāṣiṇam / pratyuvāca tataḥ samyakpraṇamyaikaṃ jagadruruḥ //

**CMP 3.5**

laukikāgamamevedaṃ bodhicittaṃ prakāśitam //

**CMP 3.6**

lokottaraṃ kathaṃ nāma pratipatsyantyāgāmikāḥ //

**CMP 3.7**

sarvadṛṣṭiprahāṇāya tvayā dharmo hi deśitaḥ / tat kathaṃ bodhicittaṃ tu sā dṛṣṭiḥ sudṛḍhīkṛtā //

**CMP 3.8**

uktamarthaṃ na budhyanti saṃdhyāyavākyamohitāḥ / yathārutaṃ te gṛṇhanti tathaiva hi pacanti ca //

**CMP 3.9**

atha bhagavān viśvo vajrapāṇiṃ vadet tataḥ / sādhu sādhu ca guhyeśa vyākṛtāgāmikā tvayā //

**CMP 3.10**

bodhicittaṃ bhavedvāyurambare ca vyavasthitaḥ / prāṇabhūtaśca sattvānāṃ pañcātmā daśasaṃjñakaḥ //

**CMP 3.11**

pratītyadvādaśāṅgākhyaṃ svabhāvāt tritayaṃ bhavet / sarvendriyapradhānedaṃ vāyvākhyaṃ bodhicittakam //

**CMP 3.12**

avyaktaṃ sūkṣmamityevaṃ vyaktamityucyate sadā / tadāśrayāttu karmāṇi kuryādviṣayādikaṃ janaḥ //

**CMP 3.13**

śāntikaṃ pauṣṭikaṃ caiva vaśyābhicārakaṃ tathā / bodhicittātu tatsarvaṃ tritattvanilayāśrayā[t] //

**CMP 3.14**

yāvaccālokasaṃketāḥ kalpitā vividhāstathā / bhavanti bodhicittāttu vikalpā vāyutaḥ sadā //

**CMP 3.15**

sukhaduḥkhādiko dharmo bījādeva vidhīyate / bodhicittasvabhāvo 'sau skandhādyadvayakopamaḥ //

**CMP 3.16**

prajñopāyaikayogena bodhicittaṃ jagad bhavet //

**CMP 3.17**

svayaṃ samuccaretsvāmī dhyānādhyayanavarjitaḥ //

**CMP 3.18**

divārātrivibhāgena candrasūryaprayogataḥ / niśvāso [hi] jagadvyāpī bodhicittaikamārutaḥ //

**CMP 3.19**

śubhāśubhaphalaṃ tyaktvā bhavatyeva nabhopamaḥ // iti /

**CMP 3.20**

prāṇāpānasamānākhyānudānavyānasaṃjñakān / nāgakūrmakṛkarāṃśca devadattadhanañjayān //

**CMP 3.21**

kṛtvaitadātmano bimbaṃ strītattvaṃ nirmāya te punaḥ // iti /

**CMP 3.22**

koṭākṣaḥ koṭavaḥ koṭāḥ koṭābhaśca koṭīrakaḥ / kolākṣaḥ kolāvaḥ kolaḥ kolābhaśca kalistathā //

**CMP 3.23**

nāsikācchidrasaṃbhūtaḥ pañcabuddhakulasthitaḥ / pañcavāyurdhvasañcāro dehe carati nityaśaḥ //

**CMP 3.24**

saṃvṛtighrāṇasañcārād dvārāttasya vinisṛtāḥ / vāmadakṣiṇadvandvāśca stabdhaścaite caturvidhāḥ //

**CMP 3.25**

dakṣiṇāt prasaro dhāturhutabhuṅmaṇḍalañca vai / raktavarṇamidaṃ vaktraṃ padmanāthasya sañcaret //

**CMP 3.26**

vāmācca prasaro dhāturvāyumaṇḍalaniḥsṛtaḥ / haritaḥ śyāmasaṃkāśaḥ karmanāthasya sañcaret //

**CMP 3.27**

dvandvasya prasaro dhātuḥ kanakavarṇasya satribhaḥ / māhendramaṇḍalañcaiva ratnanāthasya sañcaret //

**CMP 3.28**

stabdho na prasaro dhātuḥ kṣaṇādvāruṇamaṇḍalaḥ / śuddhasphaṭikasaṃkāśaṃ vajranāthasya sañcaret //

**CMP 3.29**

sarvadhātuṃ samuddhṛtya hyādhārādheyadhāritaḥ / vairocanamahākāyo maraṇānte viniścaret //

**CMP 3.30**

caturmaṇḍalametaddhi japennityaṃ samāhitaḥ / ahorātraṃ sadā jāpo mantriṇāṃ japasaṃkṣa(khya)yā //

**CMP 3.31**

ekādirnavamadhye tu daśabhiryo na badhyate / tamabaddhaṃ vijānīyāt sa vetti paramaṃ padam //

**CMP 3.32**

svaravyañjanavarṇāṃśca navasaṃkhyānuvartinaḥ / abaddhānyonyasaṃyogā yo vetti sa jagadruruḥ //

**CMP 3.33**

yo buddhā(ddhvā)vāñcchayet siddhiṃ vimuktiphalasampadam / sa tadeva samāpnoti arūpo rūpavarjitam //

**CMP 3.34**

bhūtāntena samāyuktaṃ kalādiṣoḍaśe sthitam / pañcapañcakasaṃyuktaṃ catusrayaniyojitam //

**CMP 3.35**

sānusvāraṃ sadīrghaṃ ca guṇasaṃyogalopavat / hrasvaṃ samastavākyaṃ syānna cānekaṃ na caikakam //

**CMP 3.36**

yakārārthena yatkiñcit kartavyaṃ siddhimicchatā / rephāditritayenaiva jagatkāryaṃ pravartate //

**CMP 3.37**

ye varṇāḥ pṛṣṭhataḥ proktā abhimukhāśca ye punaḥ / strīpunnapuṃsakāste ca dhātvādiparikalpitāḥ //

**CMP 3.38**

adha ūrdhvasamāyuktā jñātvā buddhyā niyojitāḥ / ṣaḍbhiruktaṃ catustrai(stryai)kānniḥsvabhāvaikabhāvajām //

**CMP 3.39**

trā(tryā)dyādyarthe samāyoja(jya) tryadhvajñānaṃ tu jāyate / svapnendrajālava dvidhvā kuryājjagat tridhātuke //

**CMP 3.40**

pratyāhāramidaṃ mantraṃ niḥsvabhāvasvabhāvajam / tataḥ pariṇataṃ rūpaṃ yad daivatopalambhakam //

**CMP 3.41**

sāṃketikaṃ tritattvasthaṃ prakṛtijāpalakṣaṇam / anākhyeyamanuccāryaṃ bodhicittamidaṃ param //

**CMP 3.42**

tadeva tritayaikaṃ syādanirgamamanāgamam / anirodhaḥ praśāntaśca śāśvatocchedavarjitam //

**CMP 3.43**

trayadhvavidākṛtasaṃkalpamākāśābhedalakṣaṇam / pāramārthikamevedaṃ pratyātmavedyalakṣaṇam //

**CMP 3.44**

sarvāsvapi kriyāścai(svai)va niṣadyādiṣu yogavit / anākhyeyamanuccāryaṃ tryadhvātītaṃ japet sadā //

**CMP 3.45**

pāṇḍarādi japaḥ(pāḥ) proktāḥ pañcaviṃśacchatadvayam / caturbhirguṇitaṃ samyak caturyogaṃ śataṃ nava //

**CMP 3.46**

navaśataṃ tu yad dṛṣṭaṃ caturviśatiparikramaiḥ / pratyutpādād bhavettatu dvyayutaṃ śataṣoḍaśam //

**CMP 3.47**

taditthaṃ guhyasandhyāyāṃ sūkṣmayogaṃ prakāśitam / dhyānādhyayanavītaṃ tu tathāpi japa ucyate //

**CMP 3.48**

akāraḥ sarvavarṇāgryo mahārthaḥ paramākṣaraḥ / mahāprāṇo hyanutpādo vāgudāhāravarjitaḥ / sarvābhilāpahetvagryaḥ sarvavāksuprabhāsvaraḥ // iti /

**CMP 3.49**

jvalantaṃ dīpasadṛśaṃ hṛdi madhyamanāhatam / akṣaraṃ paramaṃ sūkṣmam akāraṃ paramaṃ prabhum // iti /

**CMP 3.50**

dharmā ime śabdarutena vyākṛtā dharmaśca śabdaśca hi nātra labhyate / na caikatāṃ cāpyavatīrya dharmatām anuttarāṃ kṣāntivarāṃ spṛśiṣyate // iti /

**CMP 3.colophon**

vāgvivekamelāvaṇasaṃśayaparicchedastṛtīyaḥ // 3 //
