**CMP 5.1**

payodharā yathā naike nānāsaṃsthānavarṇakāḥ / ubhdūtā gaganābhogāllayaṃ gacchanti tatra vai //

**CMP 5.2**

evaṃprakṛtayaḥ sarvā ābhāsatrayahetukāḥ / nirviśya viṣayān kṛtsnān praviśanti prabhāsvaram //

**CMP 5.3**

evaṃsvabhāvā vijñānādajñāna[paṭalāvṛtāḥ / kṛtvā śubhāśubhaṃ karma bhra]manti gatipañcake //

**CMP 5.4**

ānantaryādikaṃ kṛtvā narakeṣu vipacyate / śubhaṃ dānādikaṃ kṛtvā [svargādiṣu mahīyate //

**CMP 5.5**

ānantajanmasāhasraṃ] prāpya caivaṃ punaḥ punaḥ / pūrvakarmavipāko 'yamiti śocati mohataḥ //

**CMP 5.6**

prakṛtyābhā[savidhinā kleśavantaśca ye janāḥ / etajjñātvā vimu]cyanti jñānino bhavapañjarāt // iti /

**CMP 5.7**

yadi śūnyamidaṃ sarvamanutpannasvabhāvakam / kathaṃ karmātra saṃsāre sukhaduḥkhaṃ pravartate //

**CMP 5.8**

ahaṅkāramamakāraistathārāgādibhirmalaiḥ / kalpitaṃ paratantreṇa duḥkhāt kliśyanti bāliśāḥ //

**CMP 5.9**

cittamātramidaṃ sarvaṃ māyākārasamutthitam / tataḥ śubhāśubhaṃ karma tato janma śubhāśubham // iti /

**CMP 5.colophon**

karmāntavibhāgamelāvaṇasaṃśayaparicchedaḥ pañcamaḥ // 5 //
