**CMP 2.1**

pañcaskandhāḥ samāsena pañcabuddhāḥ prakīrtitāḥ / vajra-āyatanānyeva bodhisattvāgryamaṇḍalam //

**CMP 2.2**

pṛthivī locanā khyātā abdhāturmāmakī smṛtā / pāṇḍarākhyā bhavettejastārā vāyuḥ prakīrtitā //

**CMP 2.3**

rūpaśabdādibhirmantrī devatāṃ bhāvayet sadā //

**CMP 2.4**

ityuktaṃ bhagavatā śrīguhyasamājamahāyogatantre /

**CMP 2.5**

kulāḥ śatavidhāḥ proktāḥ saṃkṣepeṇa tu pañcadhā / punastrividhatāṃ yānti kāyavākcittabhedataḥ //

**CMP 2.6**

"pañcaskandhāḥ samāsena pañcabuddhāḥ prakīrtitāḥ /"

**CMP 2.7**

pañcahṛdayamāśritya pañcatanuvinirgatam / pañcavāyusamāyuktaṃ pañcakāmopabhogakṛta // iti /

**CMP 2.8**

prakramaṇāt prāṇāyāmāccendriyadvāraistantubhiḥ / prakramate sadā kālaṃ prāṇa ityabhidhīyate //

**CMP 2.9**

vātamūtrapurīṣāṇāṃ śukrādīnāṃ tathaiva ca / apanayanādapāno 'yaṃ yogibhirlakṣyate sadā //

**CMP 2.10**

aśitaṃ khāditaṃ lehyaṃ peyaṃ coṣyañca sarvataḥ / samānayati yo nityaṃ samāna iti cocyate //

**CMP 2.11**

ūrdhvagamāt saṃharaṇād bhakṣyabhojyādibhakṣaṇāt / udānakarmavijño 'yaṃ jñānena sahayogataḥ //

**CMP 2.12**

vyāpanaṃ dhāraṇaṃ caiva gamanāgamanādikam / sarvasandhiṣu vyāptatvād vyāna ityabhidhīyate //

**CMP 2.13**

pṛthivī locanā khyātā abdhāturmāmakī smṛtā / tejaḥ pāṇḍarā khyātā vāyustārā prakīrtitā //

**CMP 2.14**

skandhaśca dhātuśca tathaivendriyaṃ ca pañcaiva pañcaiva kṛtaprabhedāḥ / tathāgatādhiṣṭhita ekaikaśaḥ saṃsārakarmāṇi kuto bhavanti //

**CMP 2.15**

tathā sabāhyā viṣayāśca pañca ekaikaśaḥ pañcatathāgataiśca / svakasvakā nityamadhiṣṭhitāste jñānatrayaṃ pañcasamāśritaṃ ca //

**CMP 2.16**

khadhātumadhyagataṃ cintenmaṇḍalaṃ sarvavajrajam / saṃhāraṃ ca prakurvīta yadīcchecchāntavajradhṛg // iti /

**CMP 2.17**

pañcātmakaṃ pañcabhireva bhūtairdṛṣṭaṃ narāṇāṃ niyataṃ śarīram / tabhdāvabhāvairniyataṃ svacittaṃ prabhāvayantaḥ prabhavanti buddhāḥ // iti /

**CMP 2.18**

khasamatantre 'pyāha- pañcabuddhātmaku sarvajago 'yaṃ paśyasu citraku nāṭaku divyam / yatra hi eku mahāsuhanāmā nṛtyati eku aneka rasena // iti /

**CMP 2.19**

"saṃkṣepeṇa tu pañcadhā"

**CMP 2.20**

kāyavākcittanidhyaptaiḥ svabhāvo nopalabhyate / mantramūrtiprayogeṇa na bodhirna ca bhāvanā //

**CMP 2.21**

vicāryedaṃ samāsena kāyavākcittalakṣaṇam / bhāvayedvidhisaṃyogaṃ samādhiṃ mantrakalpitam // iti /

**CMP 2.22**

na yogaḥ pratibimbeṣu niṣiktādiṣu jāyate / bodhicittamahāyogayoginastena devatāḥ //

**CMP 2.23**

ātmā vai sarvabuddhatvaṃ sattvasauritvameva ca / svādhidaivadya(ta)yogena tasmādātmaiva sādhayet // iti /

**CMP 2.24**

mantranidhyaptikāyena vācā manasi coditaḥ / sādhayet pravarāṃ siddhiṃ manaḥsantoṣaṇapriyām //

**CMP 2.colophon**

kāyavivekamelāvaṇasaṃśayaparicchedo dvitīyaḥ // 2 //
