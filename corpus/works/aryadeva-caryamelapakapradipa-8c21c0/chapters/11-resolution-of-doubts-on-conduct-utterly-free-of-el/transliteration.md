**CMP 11.1**

parvateṣu vivikteṣu nadīprasravaṇeṣu ca / śmaśānādiṣvapi kāryamidaṃ dhyānasamuccayam //

**CMP 11.2**

prayogādīṃśca tattvena varjayet tattvavit sadā / vajrasattvadahaṃkāraṃ muktvā nānyatra kārayet //

**CMP 11.3**

prayogā api na budhyante śuddhatattve vyavasthite / nairātmyapadayogena yāvattat pratyavekṣyate //

**CMP 11.4**

niḥsvabhāvapadasthasya divyopāyayutasya ca / siddhyate nirvicāreṇa yatkiñcit kalpacoditam //

**CMP 11.5**

bhāvanāyogasāmarthyāt svayamevopatiṣṭhate / tatsarvaṃ kṣaṇamātreṇa yatkiñcit siddhilakṣaṇam //

**CMP 11.6**

rūpādyādhyātmikān dharmān paśyet vipaśyanocyate / akṣobhyādiyathāsaṃkhyaṃ kalpayet śamatho bhavet //

**CMP 11.7**

anayorniḥsvabhāvatvāt tathatāśāntasaṃjñakam / tathatāmaṇḍale yogī sarvabuddhān praveśayed // iti /

**CMP 11.8**

nirvāṇāgnimahāgore bhasmaśo 'pi na mucyate / na tatra vidyate tattvaṃ nendriyārthā na dhātavaḥ //

**CMP 11.9**

nirvikalpo yadā viraḥ sthitiṃ hitvā tu laukikīm / ācaret sarvakāryāṇi buddhāḥ paśyanti tat tadā //

**CMP 11.10**

bālavadvicaredyuktyā sarvataśchinnasaṃśayaḥ / nirābhogo yadā yogī tadā varṣanti saṃpadaḥ //

**CMP 11.11**

aśeṣapāpayuktānāṃ mohāvaraṇasusthitāḥ / unmattavratayogena ṣaṇmāsādamoghasiddhayaḥ //

**CMP 11.12**

sarvabuddhāna svayaṃ paśyet sarvakāmaiḥ prapūryate / na kṣīṇo na ca hānitvaṃ svecchāyurjāyate vapuḥ //

**CMP 11.13**

anuttarāṃ parāṃ bodhiṃ saṃprāpnotyaprayatnataḥ / vinā yatnena sidhyanti sarvakāmasukhotsukāḥ //

**CMP 11.14**

gambhīrapadaṃ nityaṃ gacchet tiṣṭhan niṣaṇṇakaḥ / prabhāsvarajñānakauśalyād yogināṃ lakṣaṇaṃ sadā //

**CMP 11.15**

anena dhyānayogena cittaratnaṃ dṛḍhībhavet / adhiṣṭhānaṃ ca kurvanti buddhā bodhipratiṣṭhitāḥ //

**CMP 11.16**

evaṃ bhūtvā niviṣṭastu bhāvayed bhāvatatparaḥ / yāvanna khidyate cittaṃ samāhitamanāḥ sudhīḥ //

**CMP 11.17**

khinnastu paryaṭet paścādyathārucitaceṣṭitaḥ / bhāvayedvipulāṃ bodhimīṣadunmīlitekṣaṇaḥ //

**CMP 11.18**

hasan jalpan kvacittiṣṭhan kvacitkuryāt pravartanam //

**CMP 11.19**

bhāvanāsaktacittastu yathā khedo na jāyate //

**CMP 11.20**

evaṃ samādhiyuktasya nirvikalpasya mantriṇaḥ / kālāvadhiṃ parityajya siddhyate 'nuttaraṃ padam // iti /

**CMP 11.21**

sūkṣmarūpaṃ laghusparśaṃ vyāptisaṃprāptimeva ca / prakāśaṃ caiva sthairyaṃ ca vaśitvaṃ kāmāvasānikam // iti /

**CMP 11.22**

bodhijñānāgrasaṃprāptaṃ paśyati buddhasuprabham / buddhasaṃbhogakāyaṃ ca ātmānaṃ laghu paśyati //

**CMP 11.23**

traidhātukamahāsattvaiḥ pūjyamānaṃ sa paśyati / buddhaiśca bodhisattvaiśca pañcakāmaguṇairdhruvam //

**CMP 11.24**

pūjitaṃ paśyate nityaṃ mahajñānā grasambhavam / vajrasattvaṃ mahābimbaṃ vajradharmaṃ mahāyaśam //

**CMP 11.25**

svabimbaṃ paśyate svapne guhyavajramahāyaśāḥ / praṇamanti mahābuddhā bodhisattvāśca vajriṇaḥ //

**CMP 11.26**

drakṣyanti īdṛśān svapnān kāyavākcittasiddhidān / sarvalaṅkārasampūrṇāṃ surakanyāṃ manoramām //

**CMP 11.27**

dārakaṃ dārikāṃ paśyan sa siddhimadhigacchati / daśadiksarvabuddhānāṃ kṣetrasthaṃ paśyati dhruvam //

**CMP 11.28**

dadanti hṛṣṭacittātmā dharmagañjaṃ manoramam / dharmacakragataṃ kāyaṃ sarvasattvaparivṛtam //

**CMP 11.29**

paśyate yogasamaye dhyānavajrapratiṣṭhitaḥ // iti /

**CMP 11.30**

nāpaneyamataḥ kiñcit prakṣeptavyaṃ na kiñcan / draṣṭavyaṃ bhūtato bhūtaṃ bhūtadarśī vimucyate // iti /

**CMP 11.31**

uktaṃ ca suvarṇaprabhāsasūtre- na buddhaḥ parinirvāti na dharmaḥ parihīyate / sattvānāṃ paripākāya parinirvāṇaṃ nidarśayet //

**CMP 11.32**

laṅkāvatārasūtre 'pyuktam- na hyatrotpadyate kiñcit pratyayairna nirudhyate / utpadyante nirudhyante pratyayā eva kalpitāḥ //

**CMP 11.33**

ata uktam- yena yena hi bhāvena manaḥ saṃyujyate nṛṇām / tena tanmayatāṃ yāti viśvarūpo maṇiryathā //

**CMP 11.34**

utpattiryat saṃvṛtisatyametad mṛtyurhi nāma paramārthasatyam / kramadvayasyāsya gurukṛpāto jñātā bhaved yaḥ sa bhaviṣyabuddhaḥ //

**CMP 11.35**

satyadvayasyādvayavatpraveśo 'nucchedarūpo 'pyaviśeṣa eva / ekatvamevāstyanayordvayoriti vijñāyate yena vimukta eṣaḥ //

**CMP 11.36**

girīndramūrdhnaḥ prapatet tu kaścid neccheccyutiṃ sa cyavate tathāpi / guruprasādādvihitopadeśād necchedvimuktiṃ sa tathāpi muktaḥ //

**CMP 11.37**

matvā sattveṣu tattvādhigamakṣamatābhāvamālokya loke uttālābdhitaraṅgabhaṅgavikalāddīpasphuliṅgādiva / kiñcit kiñcidupetya saṃcitavatā grantho mayāyaṃ kṛto ye vai saṃvṛtisatyabhītasubhagāsteṣāmalāto bhavet //

**CMP 11.colophon**

atyantaniṣprapañcacaryāmelāvaṇasaṃśayapariccheda ekādaśaḥ //

**CMP work-colophon**

samāpto 'yaṃ caryāmelāvaṇapradīpaḥ // kṛtirīyaṃ mahācārya-āryadevapādānām //
