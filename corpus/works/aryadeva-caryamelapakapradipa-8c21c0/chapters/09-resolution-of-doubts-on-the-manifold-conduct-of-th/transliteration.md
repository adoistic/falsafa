**CMP 9.1**

phalena hetumāmudrya phalamāmudrya hetunā / vibhāvyamanyathāsiddhiṃ kalpakoṭirna jāyate // iti /

**CMP 9.2**

vajrasattvo mahārājaścodanīyo muhurmuhuḥ // iti /

**CMP 9.3**

pādaprasārikaṃ muktvā tyaktvā saṃsārapeṭakam / sādhayed vajrasattvāgraṃ nityamudyuktamānasaḥ //

**CMP 9.4**

kaukṛtyastyānamiddhādīn parityajya prayatnataḥ / anyathā naiva siddhiḥ syāt kalpakoṭiśatairapi // iti /

**CMP 9.5**

bhikṣubhāve sthitā ye 'tra ye tu tarkaratā narāḥ / vṛddhabhāve sthitā ye tu teṣāṃ tattvaṃ na deśayet // iti /

**CMP 9.6**

upāyarahitaṃ jñānaṃ śikṣā cāpi hi deśitā / śrāvakāṇāṃ mahāvīra avatā(dhā)raya teṣu vai //

**CMP 9.7**

mūlasūtre 'pyāha- daśakuśalān karmapathānicchanti jñānavarjitāḥ // iti /

**CMP 9.8**

śrāvakayānamaśikṣatha bhikṣo bodhicariyata tatra carīye / bodhicarīṃ cara buddhaguṇeṣu eṣa nidānabhaviṣya svayaṃbhūḥ // iti /

**CMP 9.9**

duṣkarairniyamaistīrvrairmūrtiḥ śuṣyati duḥkhitā / duḥkhād vikṣipyate cittaṃ vikṣepāt siddhiranyathā // iti /

**CMP 9.10**

mūlasūtre 'pyāha- duṣkarairniyamaistīvraiḥ sevyamāno na siddhyati / sarvakāmopabhogaistu sevayaṃścāśu siddhyati // iti /

**CMP 9.11**

rāgo dveṣaśca mohaśca traya ete viṣaṅgatāḥ / viṣatvamupayāntyeva viṣameṇa tu sevitā //

**CMP 9.12**

amṛtatvaṃ punaryānti, amṛtena tu sevitāḥ // iti /

**CMP 9.13**

badhyati yena jaḍaḥ parimucyati tena budhaḥ / bodhivibhāvanayā viparītamidaṃ sakalam //

**CMP 9.14**

yena mūḍhāḥ prabadhyante śīryante rauravāntike / taireva hi vimucyante sukhaṃ prajñābalena tu // iti /

**CMP 9.15**

athātaḥ saṃpravakṣyāmi sarvato viśvamuttamam / sarvabuddhasamāyogaḍākinījālasaṃvaram //

**CMP 9.16**

rahasye parame ramye sarvātmani sadā sthitaḥ / sarvabuddhamayaḥ śrīmān vajrasattvodayaḥ sukhaḥ //

**CMP 9.17**

tathāgatamahādivyaratnajālādyalaṅkṛtam / tato ghaṇṭāvasaṃsaktavitānavitatojjvale //

**CMP 9.18**

vajragītiṃ ca pūjāṃ ca gītavādyairvikurvitam / puṣpadhūpādiyogena dīpagandhādibhistathā //

**CMP 9.19**

prasādhayanti bhavane sodyānādiṣu vā punaḥ / sarvabuddhasamāyogaḍākinījālasaṃvaram //

**CMP 9.20**

tatrāsanaṃ niveśyādau mṛdusaṃsparśajaṃ sukham / viśvapadmapaṭacchannaṃ sarvaśuddhāsanaṃ hi tat //

**CMP 9.21**

sarvabuddhasamāyogaṃ yogeśvaravikurvitam / śrīvajrasattvarūpāstu vikurvanti hi yatra(tattu) vai //

**CMP 9.22**

sarvadhātumayī(yo) vāpi jīvamūlamayastathā / svādhidaivatpratimukhaiḥ siddhimudrāpravartanam //

**CMP 9.23**

niṣiktāṃ ghaṭitāṃ vāpi(bhi)saṃskṛtāṃ vā sucitritām / vicitrapratibimbāṃ ca cinhamudrāṃ prakalpayet //

**CMP 9.24**

tadāsaneṣu prāṇasarvān yathāsthānaṃ hi vinyaset / caturasraṃ caturdvāraṃ catustoraṇamaṇḍitam / vajraratnapadmādi tu dvārapālena yojayet //

**CMP 9.25**

svādhidaivatpratimukhaiḥ suprasādhitayoṣitam / svamudrācinhasubhagāṃ kalpayed gaṇamaṇḍalam //

**CMP 9.26**

caturasraṃ caturdvāraṃ catustoraṇamaṇḍitam / catuḥsūtrasamāyuktamaṣṭastambhopaśobhitam //

**CMP 9.27**

hārārddhahāraracitaṃ paṭṭasragdāmabhūṣitam / ghaṇṭāpatākasaṃśobhaṃ cāmarādivibhūṣitam //

**CMP 9.28**

candrārddhavajrakoṇaṃ ca dvāraniryūhasandhiṣu / patvi(kṣi)ṇīkramaśīrṣādivicitra paṭamaṇḍitam //

**CMP 9.29**

sarvadevyupabhogaistu sevyamānairyathāsukham / svādhidaivatayogena svamātmānaṃ prapūjayet //

**CMP 9.30**

pūjyate 'nuyogena sarvayogasukhena tu / samāsvādayamānastvatiyogena siddhyati //

**CMP 9.31**

anena sarvabuddhātmā rasāyanasukhena tu / siddhyet śrīvajrasattvāyuryauvanārogyasatsukham //

**CMP 9.32**

sarvabuddhamahākāyaḥ sarvabuddhasarasvatī / sarvabuddhamahācittaḥ sarvabuddhamahāmahaḥ //

**CMP 9.33**

sarvabuddhamahārājā sarvavajradharādhipaḥ / sarvalokeśvarapatiḥ sarvaratnādhipeśvaraḥ //

**CMP 9.34**

tābhiḥ saṃramyamāṇastu yātyutpattiṃ tu gacchataḥ / sarvadevīmahāsidhya(ddha)ścakravartī prasidhyati // iti /

**CMP 9.35**

pratyahaṃ pratimāsaṃ vā pratisaṃvatsaraṃ tathā / yathādhiṣṭhānato vāpi nāṭayed buddhasaṃvaram // iti /

**CMP 9.36**

utthito vā niṣaṇṇo vā caṃkraman vā yathāsthitaḥ / praharṣan vā jalpan vā yatra tatra yathā tathā //

**CMP 9.37**

yadyadindriyamārgatvaṃ yāyāttattatsvabhāvataḥ / asamāhitayogena sarvabuddhamayaṃ vahet //

**CMP 9.38**

khasamaṃ khasamākāramaparyantasāgaropamam / rāgadharmanayo dveṣo vilāsaḥ krīḍāvistaraḥ //

**CMP 9.39**

gṛhītaṃ vastumātraṃ ca śiṣyabodhanakāraṇāt / kati janmāntaraṃ vaktuṃ sahyate rāgadeśanā //

**CMP 9.colophon**

śrīsarvabuddhasamāyogaḍākinījālasaṃvaranyāyena bodhisattvacaritadharmodayābhisaṃbodhiprapañcatāmelāvaṇa-saṃśayaparicchedo navamaḥ // 9 //
