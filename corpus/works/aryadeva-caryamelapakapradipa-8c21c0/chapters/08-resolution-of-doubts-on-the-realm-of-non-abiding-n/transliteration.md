**CMP 8.1**

sthūlaṃ śabdamayaṃ prāhuḥ sūkṣmaṃ cittāmayantathā / cittayā rahitaṃ yat tad yogināṃ paramaṃ padam // iti /

**CMP 8.2**

svasaṃvedyaṃ tu tattattvaṃ vaktuṃ nānyasya pāryate / bhaktibhāvanayā gamyaṃ na gamyaṃ cānyathā nu tat //

**CMP 8.3**

jñātvā tattvaṃ tataḥ kṛtvā bhaktibhāvamaharniśam / tasmin paramanirvāṇe pade śānte hyanuttare //

**CMP 8.4**

tatastadbhaktisāmarthyād bhāvanābalanirmitam / tasminnutpadyate rūpaṃ kimapyānandajaṃ param //

**CMP 8.5**

dhagityākārasaṃbhūtaṃ sphuratsaṃhārākārakam / bhūrbhuvaḥsvaridaṃ sarvaṃ dyotayat sacarācaram //

**CMP 8.6**

bhāvanābalasāmarthyāt prajñopāyātmakaṃ śivam / sarvakleśavinirmuktaṃ sarvalakṣaṇabhūṣitam //

**CMP 8.7**

śūnyatājñānasaṃbhūtaṃ nirdvandvaṃ paramaṃ śivam / sarvākāravaropetaṃ grāhyagrāhakavarjitam //

**CMP 8.8**

jñānaṃ māyopamaṃ śuddhaṃ svacchaṃ prakṛtinirmalam / śabdagandharasātītaṃ tathā sparśavivarjitam //

**CMP 8.9**

dṛśyate paramekena samādhau jñānacakṣuṣā / chāyāmāyopamaṃ divyaṃ divyasaṃsthānasayutam //

**CMP 8.10**

sphurajjñānormimālābhirvividhānekavigraham / indrāyudhanibhaṃ kāyaṃ labhante tattvabhāvakāḥ //

**CMP 8.11**

bhāvanāyogasāmarthyāt samayānāṃ ca pālanāt / īdṛśaṃ prāpyate rūpaṃ na vācyaṃ yajjinairapi //

**CMP 8.12**

yatra kāyo na vākcittaṃ sthānaṃ yatsarvagaṃ param / saṃpradāyavaśāt tatra svasya rūpaṃ vibhāvyate //

**CMP 8.13**

aho suvismayakaramaho śāntamatīndriyam / aho paramagambhīraṃ buddhatvaṃ padamuttamam // iti /

**CMP 8.14**

aho vajra aho vajra aho vajrasya deśanā / yatra na kāyavākcittaṃ tatra rūpaṃ vibhāvyate // iti /

**CMP 8.15**

bhaṭṭārakapādenāpyuktam- śauśīryaṃ nāsti te kāye māṃsāsthirudhiraṃ na ca / indrāyudhamivākāśe kāyaṃ darśitavānasi //

**CMP 8.16**

nāmayo nāśuciḥ kāye kṣuttṛṣṇāsaṃbhavau na ca / tvayā lokānuvṛttyarthaṃ darśitā laukikī kriyā // iti /

**CMP 8.17**

sarvakalpasamuccaye 'pyāha-

**CMP 8.18**

gṛhītvā hṛdayaṃ śuddhaṃ vajradehavibhāvanā / dṛḍhaṃ sāramasauśīryaṃ vajrakāyaṃ sa labdhavān // iti /

**CMP 8.19**

khasamā virajā vararūpadharā aśarīra alakṣaṇa prajñasutā / sugambhīraguṇodadhi kāruṇikā dada mūrdhni pāṇi mama apratimā // iti /

**CMP 8.colophon**

apratiṣṭhitanirvāṇadhātumelāvaṇasaṃśayaparicchedo 'ṣṭamaḥ // 8 //
