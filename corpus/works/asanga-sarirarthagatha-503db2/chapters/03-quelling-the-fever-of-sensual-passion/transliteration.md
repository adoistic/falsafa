**Śag_3.1**

kāmarāgābhibhūtatvāc cittaṃ me paridahyate / aṃga me gautama brūhi śāntiṃ tvam anukaṃpayā //

**Śag_3.2**

viparyāsena saṃjñānāṃ cittaṃ te paridahyate / nimittaṃ varjyatāṃ tasmāc chubhaṃ rāgopasaṃhitaṃ //

**Śag_3.3**

aśubhāṃ bhāvaya sadā tvam ekāgraḥ susamāhitaḥ / nirvāpayāśu rāgāgniṃ dahyase mā punaḥ punaḥ //

**Śag_3.4**

saṃskārāvaratāṃ paśya duḥkhato 'nātmatas tathā / smṛtiṃ kāyagatāṃ kṛtvā nirvedabahulo bhava //

**Śag_3.5**

bhāvyatām animittaṃ ca mānānuśayanāśanaṃ / tato mānābhisamayād duḥkhasyāntaṃ kariṣyasi //
