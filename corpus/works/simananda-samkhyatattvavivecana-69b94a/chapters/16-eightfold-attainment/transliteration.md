**Tats_15**

aṣṭadhā siddhiḥ ||

**Tats_15.c1**

jñānaṃ yaddūramutpannaṃ tārākhyā prathamā hi sā / śabdamātreṇa bhūteṣu sutārā jñānamiṣyate //

**Tats_15.c2**

jñānamadhyayanenaiva tārayantī tṛtīyakā / adhyātmaduḥkhāpanayāt pramodetyabhidhīyate //

**Tats_15.c3**

bhautikakleśaharaṇāt pramudā siddhirucyate / ādhidaivakleśaharaṇāt jñānamutpadyate nṛṇām //

**Tats_15.c4**

pramodamānetyākhyātā ṣaṣṭhī siddhiḥ svayaṃ satām / snigdhasaṃsarganāśāttu ramyakā saptamī smṛtā //

**Tats_15.c5**

pramudā cāṣṭamī siddhiḥ paricaryādinā guroḥ / ityetāḥ siddhayo hyaṣṭau vyākhyātāḥ jñānasādhikāḥ //
