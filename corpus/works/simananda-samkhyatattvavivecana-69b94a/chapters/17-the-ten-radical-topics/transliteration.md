**Tats_16**

daśa mūlikārthāḥ ||

**Tats_16.c1**

astitvamekatvayathārthavattve pārārthyamanyatvamakartṛkatvam / yogo viyogo bahavaḥ pumāṃsaḥ sthitiḥ śarīrasya ca śeṣavṛttiḥ //

**Tats_16.c2**

eṣā sā daśamūlikā 'rthagaṇanā saṅghātapārārthyataḥ siddhā sā puruṣāstitā pariṇaterbhedasya tatkāraṇam / astyavyaktamanantamekamiti ca premāviṣādātmakaṃ nānāpāyaparārthatā triguṇato 'nyatvasya siddhistathā //

**Tats_16.c3**

viparyāsādakartṛtvaṃ yogaḥ puruṣadarśanāt / prāpte śarīrabhede tu caritārthatvadarśanāt //

**Tats_16.c4**

janmādikaraṇāntānāṃ bhedānnānā hi te smṛtāḥ / cakrabhramivat śeṣavṛttiḥ siddhārthāḥ daśa mūlikāḥ //

**Tats_16.c5**

saptatyā prāgupadiṣṭāḥ pañcāśat pratyayā ime / daśaṣaṣṭipadārthaistu ṣaṣṭitantra itīryate //
