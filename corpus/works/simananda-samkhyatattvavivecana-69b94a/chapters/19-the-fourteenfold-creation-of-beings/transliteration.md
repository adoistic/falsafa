**Tats_18**

caturdaśavidho bhūtasargaḥ ||

**Tats_18.c1**

aṣṭavikalpaṃ daivaṃ paiśācaṃ rākṣasaṃ tadvat / gāndharvamaindraṃ brāhmaṃ ca saumyaṃ brāhmyamathāṣṭakam //

**Tats_18.c2**

devayonaya evaite tiryagyonistu pañcadhā / mṛgapaśupakṣisarīsṛpasthāvaramiti bhedasambhinā //

**Tats_18.c3**

mānuṣyakaṃ caikavidhaṃ brāhmaṇādicāṇḍālāntam / paśavo gavādimūṣāntāḥ pakṣiṇo garūḍādikāḥ //

**Tats_18.c4**

maśakāntā mṛgāścāpi siṃhādi ca śivāntikāḥ / śeṣādi alagardāntāḥ sarpāḥ parvatabhūtṛṇāḥ //

**Tats_18.c5**

sthāvarā bhautikaḥ sarga etatsaṃsāramaṇḍalam //
