**Tats_3**

puruṣaḥ ||

**Tats_3.c1**

puri śayanāt pramāṇāt pūraṇāt puruvṛttitaḥ / sa cānādiḥ sarvagataścetano nirguṇo 'paraḥ //

**Tats_3.c2**

draṣṭā bhoktā kṣetravidamalo 'prasavadharmakaḥ / sūkṣmo nityo hyanādistvamadhyanidhano 'pi saḥ //

**Tats_3.c3**

sarvamāptamaneneti tasmāt sarvagatastu saḥ / sukhopalabdhimattvācca cetano nirguṇastathā //

**Tats_3.c4**

sattvādiguṇarāhityāt paraḥ paratayā smṛtaḥ / dṛśyaprakṛtisambandhāt draṣṭā bhoktā 'nubhāvanāt //

**Tats_3.c5**

kṣetre guṇagataṃ vetti kṣetrajña iti kīrttitaḥ / śubhāśubhādisaṃsargābhāvādamala īṣyate //

**Tats_3.c6**

nirbījatvāt prasūte ca netyaprasavadharmakaḥ / niraṅgatvātīndriyatvāt sūkṣmo nityaḥ sadātanāt //

**Tats_3.c7**

evaṃ sāṃkhyaḥ sa puruṣo vyākhyātaḥ pūrvasūribhiḥ / jīvo jantuḥ pumānātmā puruṣaḥ pūjako naraḥ //

**Tats_3.c8**

kṣetrajñaścākṣaraḥ prāṇaḥ koya eṣaḥ sa jñastathā / aja etāni nāmāni sāṃkhye puruṣasañjñite //

**Tats_3.c9**

evam, pañcaviṃśatitattvajño yatra kutrāśrame rataḥ / muṇḍī jaṭī śikhī vāpi mucyate nātra saṃśayaḥ //

**Tats_3.c10**

ayaṃ kartā 'thavā 'karttā puruṣaḥ prakṛteḥ paraḥ / śubhāśubhāni karttā cet kuryādvṛttitrayaṃ vinā // lokadṛṣṭaguṇānāṃ cet kartṛtā dharmitā katham //

**Tats_3.c11**

sāhityaṃ yamaniyamaniṣecanaprasaṃkhyānāt / jñānaiśvaryavikāraprakāśane sāttvikī vṛttiḥ //

**Tats_3.c12**

rāgaḥ krodho lobhaḥ paraparivādo nindā tuṣṭiḥ / vikṛtākṛtapāruṣyaṃ prakhyātaiṣā rajobuddhiḥ //

**Tats_3.c13**

unmādamadaviṣādā nāstikyaṃ strīprasaṅgitā / nidrālasyaṃ nairghṛṇyaṃ tvaśaucamiti tāmasī vṛttiḥ //

**Tats_3.c14**

etadvṛttitrayaṃ dṛṣṭvā guṇānāṃ kartṛtā 'thavā / akartā puruṣaḥ siddha iti siddhānta iṣyate //

**Tats_3.c15**

pravarttamānaprakṛterimān guṇān rajastamobhyāṃ viparītadarśanāt / ātmānamācchādya sa ātmane tad ahaṅkaromītyabudho 'vamanyate //

**Tats_3.c16**

bālāgrakukṣīkaraṇāsamarthaḥ sarvaṃ mayedaṃ kṛtamityamanyata / unmattavadbhāvyata ityabodhaḥ aho vidhe paṇḍitamāninaḥ kaḥ //

**Tats_3.c17**

taduktaṃ gītāsu prakṛteḥ kriyamāṇāni guṇaiḥ karmāṇi sarvaśaḥ / ahaṅkāravimūḍhātmā kartā 'hamiti manyate //

**Tats_3.c18**

anāditvānnirguṇatvāt paramātmā 'yamavyayaḥ / śarīrastho 'pi kaunteya na karoti na lipyate //

**Tats_3.c19**

prakṛtyaiva ca karmāṇi kriyamāṇāni sarvaśaḥ / yaḥ paśyati sadā ''tmānamakartāraṃ sa paśyati // ityādi /

**Tats_3.c20**

sa ekaḥ puruṣaḥ kiṃ vā nāneti ca vicāraya / sukhaduḥkhamohasaṅkaraviśuddhajanmamaraṇānām / nānātvāt puruṣabahutvaṃ siddhaṃ lokāśramavarṇabhedācca //

**Tats_3.c21**

yadyekaḥ puruṣaḥ syād buddhihāniḥ prasajyate / ekasmin sukhite sarve sukhinaḥ syurataḥ param / ekasmin duḥkhite sarve duḥkhitāḥ syuriti kramāt //

**Tats_3.c22**

ato bahutvaṃ saṃsiddhaṃ bahavaḥ puruṣāḥ smṛtāḥ / ākṛtigarbhāśayabhāvasaṅgatiśarīravibhāgālliṅgabahutvāt sāṃkhyācāryāḥ kapilāsuripañcaśikhapatañjaliprabhṛtayaḥ puruṣabahutvaṃ varṇayanti |

**Tats_3.c23**

vedavādina ācāryā hariharahiraṇyagarbhavyāsādaya ekamātmānaṃ, tathā ca śrutiḥ | puruṣa evedaṃ sarvaṃ yadbhūtaṃ yacca bhāvyam | utāmṛtatvasyeśāno yadanyenātirohati / tadevāgnistadādityastadvāyustadu candramāḥ //

**Tats_3.c24**

tadeva śukraṃ tadbrahma tā āpaḥ sa prajāpatiḥ / tadeva satyamamṛtaṃ sa mokṣaḥ sā parā gatiḥ //

**Tats_3.c25**

tadakṣaraṃ tatsaviturvareṇyaṃ yasmāt paraṃ nāparamasti kiñcit / yasmānnāṇīyo na jyāyo 'sti kiñcit //

**Tats_3.c26**

vṛkṣa iva stambho divi tiṣṭhatyekaḥ tenedaṃ pūrṇaṃ puruṣeṇa / sarvataḥ pāṇipādaṃ tat sarvato 'kṣiśiromukham //

**Tats_3.c27**

sarvataḥ śrutimalloke sarvamāvṛtya tiṣṭhati / sarvendriyaguṇābhāsaṃ sarvendriyavivarjitam //

**Tats_3.c28**

sarvasya paśumīśānaṃ sarvasya śaraṇaṃ mahat / sarvataḥ sarvasattvāni sarvātmā sarvasambhavaḥ //

**Tats_3.c29**

sarvaṃ vilīyate yasmin tadbrahma munayo viduḥ / eka eva hi bhūtātmā bhūte bhūte vyavasthitaḥ //

**Tats_3.c30**

ekadhā bahudhā caiva dṛśyate jalacandravat / sa hi sarveṣu bhūteṣu sthāvareṣu careṣu ca // vasatyeko mahānātmā yena sarvamidaṃ tatam // ityādi /
