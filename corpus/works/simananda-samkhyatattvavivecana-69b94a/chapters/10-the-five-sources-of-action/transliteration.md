**Tats_9**

pañca karmayonayaḥ ||

**Tats_9.c1**

dhṛtiḥ śraddhā sukhecchā vividiṣā tadabhāvakau / sāmānyataḥ samuddiṣṭāḥ pañcaite karmayonayaḥ //

**Tats_9.c2**

vāci karmaṇi saṃkalpe pratītiryābhirajyate / tanniṣṭhastatpratiṣṭhaśca dhṛteretaddhi lakṣaṇam //

**Tats_9.c3**

anasūyā brahmacaryaṃ yajanaṃ yājanaṃ tapaḥ / pratigrahaśca homaśca śraddhāyā lakṣaṇaṃ smṛtam //

**Tats_9.c4**

sukhaṃ sukhārthī seveta vidyā karma tapāṃsi ca / prāyaścittaparo nityaṃ sukheyaṃ parikīrttitā //

**Tats_9.c5**

viṣadhūmamūrchitavad vividiṣā dhyānināṃ prajñāyoniḥ / ekatvaṃ ca pṛthaktvaṃ ca nityaṃ vedamacetanam //

**Tats_9.c6**

sūkṣmasatkāryasaṃkṣobhyaṃ jñeyā vividiṣā hi sā / kāryakaraṇakṣamakarī vividiṣā prākṛtī vṛttiḥ //

**Tats_9.c7**

dhṛtiḥ śraddhā vividiṣā sukhā ceti catuṣṭayam / jñeyaṃ bandho vividiṣā mokṣāya parikalpitā / karmayonisvarūpo 'yaṃ viśiṣya parikīrttitaḥ //
