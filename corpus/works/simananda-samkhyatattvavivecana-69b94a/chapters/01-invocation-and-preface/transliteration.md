**0.title**

sāṃkhyatattvavivecanam śrīṣimānandaviracitam /

**0.1**

raghunandanasutenedamiṣṭikāpuravāsinā / kānyakubjadvijāgryeṇa ṣimānandena tanyate // 1 //

**0.2**

sāṃkhyopajña namastubhyaṃ kapilāya mahātmane / pañcaviṃśatitattvānāṃ tattvajñānapravartakaḥ // 2 //

**0.3**

duḥkhatrayābhibhūtasya śāntirme syāt kutastviha / tathopadiśa janmādi yathā na syāt kṛpānidhe // 3 //

**0.4**

evaṃ pṛṣṭo muniḥ prāha nirviṇṇāya kṛpānidhiḥ / pañcaviṃśatisūtrāṇi vyākhyātāni mahātmabhiḥ // 4 //

**0.5**

babandhuḥ kavayaḥ kāvye vyācikhyuḥ kavayaḥ pare / sāṃkhyaśāstrasya yāthārthyaṃ tadevedaṃ vivicyate // ṣimānandena mandena kukṣimbhariśatādinā // 5 //
