**Tats_12**

pañcaparvāvidyā ||

**Tats_12.c1**

tamo moho mahāmohastāmisraścāndhatāmisraḥ //

**Tats_12.c2**

aṣṭakau tau tamau mohau prakṛtyaṣṭakaniṣṭhitau / ātmajñānābhimānyeyaṃ prāptyādyaiśvaryamānitā //

**Tats_12.c3**

nirvṛtte viṣaye dṛṣṭe pañcānuśravike tathā / moho 'hamabhimāno yo mahāmoho daśātmakaḥ //

**Tats_12.c4**

aṣṭaiśvarye daśaviṣaye siddhatāmisra ucyate / viṣādaḥ so 'ndhatāmisro maraṇe pratipadyate //

**Tats_12.c5**

avidyā pañcaparvaiṣā bhinnā dvāṣaṣṭibhedataḥ /
