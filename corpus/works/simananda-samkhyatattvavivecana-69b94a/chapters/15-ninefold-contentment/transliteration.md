**Tats_14**

navadhā tuṣṭiḥ ||

**Tats_14.c1**

prakṛtau paramātmatvaṃ pratipadyaiva tuṣṭibhāk // mādhyasthyamavalambeta ambhaḥ sā tuṣṭirucyate / buddhau ca paramātmatve tuṣṭiḥ sā salilā smṛtā //

**Tats_14.c2**

ahaṃkāre yadā sā syādāyācchā iti śabdhitā / tanmātreṣu yadā sā syāt tuṣṭirdṛṣṭirnigadyate //

**Tats_14.c3**

ādhyātmikāścatasrastu tuṣṭayaḥ prabhavanti hi / mokṣastāsvapi nāstyeva tattvajñānādyathoditā //

**Tats_14.c4**

arthānāmarjane duḥkhamarjitānāṃ ca rakṣaṇe / tyāge duḥkhaṃ kṣaye duḥkhaṃ dhigarthaṃ duḥkhabhājanam // iti

**Tats_14.c5**

doṣadarśanasantuṣṭaḥ parabrahmaiva mokṣabhāk / suteyaṃ pañcamī tuṣṭistattvajñānādyabhāvataḥ //

**Tats_14.c6**

rakṣaṇe sutarā ṣaṣṭhī saptamī kṣayadarśanāt / sunetrā saṅgadoṣā cāṣṭamī kurmarīcikā //

**Tats_14.c7**

arthe hiṃsādidoṣeṇa nivṛttiśca samaskarī / tuṣṭistu navamī proktā hyuttamāmbhasikā tava //
