**Tats_7**

adhyātmam adhibhūtam adhidaivataṃ ca ||

**Tats_7.c1**

buddhyāhaṅkāramanasī śrotraṃ tvak cakṣuṣī tathā / jihvā ghrāṇaṃ pādapāyūpasthamadhyātmasañjñitam //

**Tats_7.c2**

yattu mokṣadharme ādau mana ahaṅkārāt jāyate vṛttayascatāḥ // śabdarāgāt śrotramasya jāyate bhāvitātmanaḥ / rūparāgāt tathā cakṣurghrāṇaṃ gandhajidhṛkṣayā //

**Tats_7.c3**

ityādinendriyāṇāṃ manovṛttirāgādikāryatvaṃ tadvedāntarītyaiveti mantavyam | adhibhūtam |

**Tats_7.c4**

yathākrameṇa boddhavyamabhimantavyameva ca / saṅkalpitavyaṃ śrotavyaṃ spraṣṭavyaṃ draṣṭavyameva ca //

**Tats_7.c5**

rasayitavyaṃ ghrātavyaṃ gantavyamutsraṣṭavyaṃ ca / ānandayitavyamityevamadhibhūtaṃ prakīrtitam //

**Tats_7.c6**

adhidaivataṃ ca / brahmā rudraścandramāśca ākāśo vāyureva ca / sūryo varuṇa indraśca viṣṇumitraṃ tathaiva ca //

**Tats_7.c7**

anenaiva krameṇedaṃ saṃproktamadhidaivatam / catvāri yo vedayate yathā cakṣuṣā svarūpāṇyadhidaivataṃ vā / vimuktayāthāgatadoṣasaṅgo guṇāṃstu bhuṅkte na guṇaiḥ sa yujyate //
