**Tats_4**

traiguṇyam ||

**Tats_4.c1**

sattvaṃ rajastama iti guṇāḥ bhāveṇyastraiguṇyam / prasādo lāghavaṃ saṅgaḥ prasaṅgāt prītirārjavam //

**Tats_4.c2**

tuṣṭistitikṣā sattvasya rūpaṃ sākṣāt sukhāvaham / śokastambhadveṣatāpakhedabhogābhimānitā //

**Tats_4.c3**

rajorūpāṇyanekāni bahuduḥkhapradāni vai / tamo nāmācchādanādi bībhatsāvaraṇādi ca //

**Tats_4.c4**

dainyagauravanidrādipramādālasyalakṣaṇam / mohātmakamanantaṃ tadevaṃ traiguṇyamīritam / sattvaṃ prakāśakaṃ vidyādrajo vidyāt pravarttakam //

**Tats_4.c5**

vināśakaṃ tamo vidyāt traiguṇyaṃ nāma sañjñitam /
